# ToF PPO 다차로 보상 모델

`model.pt`는 기존 Windows 평가에서 100회 중 **81회 완주, 차량 충돌 15회, 순간이동 0회**를 기록한 체크포인트다. 경로 이탈은 1회, 신호 위반은 3회였다. [평가 요약](evaluation_100_seed2326_summary.json)

다차로 보상은 경로 앞쪽 600 m의 차로 연결을 비교한다. 안전한 차로 변경을 실행해 앞으로 필요한 최소 변경 횟수를 줄였을 때 `+0.1`을 주는 설정으로 실험했다. 경로 연결과 감지한 주변 차량을 사용하며, 보상 계산에 특정 도로 ID를 지정하지 않는다.

## 학습 계보

| 단계 | 체크포인트 | 근거 |
| --- | --- | --- |
| 기존 ToF PPO | [`tof_norule_b_cont/model.pt`](../run_20261119_203130_tof_norule_b_cont/model.pt) | 다차로 40k 학습 안내에서 초기 모델로 지정했다. 기존 300회 평가는 [별도 JSON](../eval300/tof_norule_b_cont.json)에 있다. |
| 다차로 보상 40k | `results/run_*_tof_multi_lane_bonus_40k/checkpoints/model_40960.pt` | 최종 60만 단계의 학습 안내에서 이 체크포인트를 `--init-model`로 지정했다. 원본 파일은 이 커밋에 포함되지 않았다. |
| 다차로 보상 600k | [model.pt](model.pt) | 실제 Windows 100회 평가에 쓰인 모델이다. |

`40,960 → +559,040` 스텝은 당시 안내 명령에 지정한 값이다. 최종 실행의 원본 `hparams.json`은 확인하지 못했다.

## 비교 실험

| 실험 | 완주/100 | 충돌/100 | 순간이동/100 | 경로 이탈/100 |
| --- | ---: | ---: | ---: | ---: |
| 합류 간격 보상 20k | 65 | 27 | 2 | 3 |
| 교차로 양보·경로 정체 보상 20k | 19 | 11 | 67 | 0 |
| 다차로 보상 600k | 81 | 15 | 0 | 1 |
| 다차로 모델에서 교차로 조기 양보 보상 추가 600k | 69 | 14 | 13 | 0 |

수치는 기록된 100회 평가 기준이다. 교차로 조기 양보 실험에서는 `377057231_4`에서 순간이동이 13회 발생해 다차로 모델을 대표 모델로 유지했다.

## 교차로 재현

저장소 루트에서 아래 명령을 실행하면 기록된 충돌 시드 8개를 재생한다. 진단 스크립트의 차로 ID는 원본 로그와 재현 결과를 대조하는 데 사용한다.

```cmd
py -u tools\trace_tof_junction_81.py
```

검증 환경에서는 8개 중 2개가 원래 충돌 차로 및 스텝과 일치했다. 시드 `2401`과 `2424`에서는 실제 충돌 상대가 각각 6.0초와 7.5초 전에 감지됐다. PPO에는 5.0초와 5.5초 전에 교차 위험이 표시됐으며 두 경우 모두 감속 명령이 없었다. 다른 6개는 원래 결과와 달랐다. [스텝별 재현 기록](junction_replay.csv)
