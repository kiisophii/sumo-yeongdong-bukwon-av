# 철도박물관 주차장 → 광교박물관 PPO 실험

평가는 museum 시나리오에서 시드 2026부터 2125까지 100회, 에피소드별 SUMO 재시작으로 진행했다. 세 관측 실험은 SUMO의 차로 연결과 차량의 현재 경로를 이용한다.

| 실험 | 코드 커밋 | 추가 학습 | 완주 | 경로 이탈 | 차량 충돌 | 신호 위반 | 순간이동 |
|---|---|---:|---:|---:|---:|---:|---:|
| 차로 변경 횟수 관측 | `85f8bdc` | 600,000 | 26 | 59 | 14 | 1 | 0 |
| 차로 변경까지 남은 시간 반영 | `6175a3e` | 600,000 | 79 | 9 | 8 | 4 | 0 |
| 합류 차로 앞뒤 차량 관측 보완 | `9af3b77` | 600,000 | 평가 JSON 참조 | 평가 JSON 참조 | 평가 JSON 참조 | 평가 JSON 참조 | 평가 JSON 참조 |

각 실험은 새로 초기화한 모델이 아닌 이전 PPO 체크포인트에서 추가 학습했다. 차로 변경 횟수와 남은 시간 실험은 같은 시작 체크포인트를 사용했고, 합류 관측 보완 실험은 79회 완주 모델에서 시작했다. 도로 ID로 구간을 지정했던 선행 실험의 별도 결과 파일은 이 목록에 포함하지 않았다.

## 평가 설정

학습 때 사용한 코드 커밋에서 `TEAM14_SCENARIO=museum`을 설정한다. 합류 관측 모델을 평가할 때 `TEAM14_MERGE_GAP_OBS=1`도 설정한다. Windows CMD에서 `%RUN%`은 평가할 실험 폴더다.

```cmd
py -u tools\evaluate.py --model "%RUN%\model.pt" --episodes 100 --seed 2026 --independent-seeds --no-baseline --out "%RUN%\evaluation_repeat.json"
```
