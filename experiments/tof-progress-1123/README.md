# 11/23 새 모델: ToF 관측 + 경로 차선 관측 제거 + 주행 결과 보상

조교 답변: 1(차선변경 안전 검사)·3(출발 시 예상 통행시간으로 경로 선택)만 OK.
2(경로 차선 관측)·4(제한속도 자르기)는 빼야 함. 기존 모델에서 이어서 학습하지 않고 처음부터 학습한다.

| 환경변수 | 내용 |
|---|---|
| `TEAM14_TOF_OBS=1` | 주변 차·신호·교차로를 ToF 센서(건물·차량 가림 포함)로 본다 (김준희 ToF 관측) |
| `TEAM14_TOF_REAR_DENSITY=1` | 좌우 후방 ToF 밀도 2칸 |
| `TEAM14_ROUTE_OBS=none` | 경로 차선 5칸 제거, 대신 구간 제한속도 1칸 |
| `TEAM14_DROP_SIGNAL_TIME=1` | 신호 남은 시간 칸 제거 (ToF로는 볼 수 없어 늘 같은 값) |
| `TEAM14_NO_SPEED_CAP=1` | 제한속도에서 자르지 않음 (차량 최고속도만) |
| `TEAM14_REWARD=progress` | 아래 보상만 사용 |

## 관측 (34칸)

| 번호 | 내용 |
|---|---|
| [0] | 내 속도 / vmax |
| [1]–[20] | 차선 5개(좌2·좌1·현재·우1·우2) × (앞차 거리, 앞차 상대속도, 뒤차 거리, 뒤차 상대속도). ToF에 보이는 차만 |
| [21] | 구간 제한속도 / vmax |
| [22]–[26] | 차선 5개 앞쪽 밀도. ToF에 보이는 차 기준, 가려서 확인 못 하면 −1 |
| [27]–[28] | 신호: 거리/150 m, 색(초록 +1·노랑 0·빨강 −1). 신호가 가렸거나 150 m 밖이면 [1, 0], 신호 없으면 [1, 1] |
| [29]–[31] | 비신호 교차로: 거리/150 m, 내가 양보 +1, 교차 차량 보임 +1 / 안 보이고 확인됨 −1 / 가려서 모름 0 |
| [32]–[33] | 좌·우 후방 밀도 (ToF) |

## 보상

| 항 | 값 |
|---|---|
| 전진 | 스텝마다 `PROGRESS_TOTAL(20) × 전진 거리 / 경로 길이` |
| 완주 (정해진 경로 끝 도착) | +10, 종료 |
| 충돌·경로 이탈·순간이동·신호 위반 | −10, 종료 |
| 과속 | 스텝마다 `PROGRESS_OVERSPEED_W(0.1) × max(0, 속도/제한속도 - 1)` 감점 |
| 시간 초과 (1,800초) | 0, 종료 |

## 학습 / 평가 (Git Bash, 저장소 루트)

```bash
bash experiments/tof-progress-1123/train.sh 0 1000000
bash experiments/tof-progress-1123/eval.sh results/<run 폴더>/model.pt 100
```

학습 로그 앞부분에 `obs_dim=34`가 나오고 `이어서 학습:` 줄이 없어야 한다.
