# ToF PPO 교차로 양보 실험

출발점은 SUMO `museum` 경로에서 100회 중 81회 완주한 [다차로 보상 모델](../../results/run_20261120_202557_tof_multi_lane_bonus_600k/README.md)이다. 전체 경로 완주율과 신협오거리에서 ToF 위험 감지 후 실제 감속하는지를 각각 평가했다. 목표 교차로 내부 차로는 `:1681517542_4_0`이다.

## 실험별 변경사항과 결과

|---|---|---|---|

| 양보 후 통과 보너스 | 감속과 무충돌 통과가 함께 보상되는가 | 위험 감지 중 PPO 제동과 실제 감속을 확인하고, 위험 표시가 꺼진 뒤 진입해 무충돌로 빠져나오면 +1점 | 학습 중 보너스 26회. 두 시드에서 제동 0회, 목표 교차로 충돌 |
| 가감속 출력층 0.5배 조정 및 20,480스텝 추가 학습 | 최대 가속에 가까운 출력을 완화하면 주행이 개선되는가 | 81회 모델의 가감속 출력층 가중치와 편향을 시작할 때 한 번 0.5배로 조정. 이후 135대/시간, 집중 학습 목표 25%, +1점 보너스로 PPO 학습 | 같은 100개 시드에서 0.5배 조정 직후 80회 → 추가 학습 후 85회 완주. 목표 교차로 차로 충돌은 4회 → 5회 |
| 집중 학습 목표 50% | 양보 경험을 두 배 가까이 늘리면 평가에서도 제동하는가 | 같은 0.5배 초기 모델에서 시작해 집중 학습 목표만 25% → 50%로 증가 | 실제 9,604스텝(46.9%) 집중, 위험 감지 1,908스텝, 위험 중 실제 감속 224스텝, 통과 보너스 53회. 중간·최종 모두 `2420` 충돌, `2424` 완주. 두 시드 모두 위험 감지 뒤 진입 전 제동 0회 |
| PPO 업데이트 진단 | 샘플링한 제동이 정책 평균을 바꾸는가 | 4,096스텝 동안 위험 관측의 행동, GAE `advantage`, 가감속 평균 업데이트 전후를 CSV에 기록 | 검증 실행에서 364행 기록. 같은 시드에서 기록 기능을 켠 실행과 끈 실행의 2,048·4,096스텝 체크포인트 가중치 일치. 별도 성능 평가 결과는 아직 확인하지 않음 |

양보 시범 주행을 활용한 지도학습도 별도로 시험했다. ToF가 위험을 감지하면 제동을 넣어 성공 예시를 모았고, 그 예시로 가감속 출력층을 학습하자 `2401`, `2424`에서 각각 진입 전 9스텝 감속하고 완주했다. 시범 생성에 제동 규칙을 사용했으므로 PPO 보상 학습 비교에는 넣지 않았다.

## 같은 100개 시드의 비교

0.5배 초기 모델과 추가 학습 모델은 시드 `2326~2425`를 같은 순서로 평가했다. 실패 → 완주 9회, 완주 → 실패 4회였다. 전체 차량 충돌은 17회 → 14회였다. 목표 차로 충돌은 4회 → 5회였다.

| 모델 | 완주 / 100 | 전체 차량 충돌 / 100 | 목표 차로 충돌 / 100 |
|---|---:|---:|---:|
| 81회 완주 기준 모델 | 81 | 15 | 기록된 기준 평가에서 8 |
| 0.5배 조정 직후 모델 | 80 | 17 | 4 |
| 0.5배 초기 모델에서 20,480스텝 학습, 집중 목표 25% | 85 | 14 | 5 |

이 비교에서 전체 경로를 가장 많이 완주한 체크포인트는 85회 모델이다. 교차로에서 ToF 위험 감지 후 제동하는지는 별도 지표로 남긴다. 조정 직후 모델은 `2420`, `2424`에서 모두 완주했으며, 위험 감지 후 실제 감속은 두 경우 모두 0회였다.

## 학습과 평가에 사용한 ToF 설정

| 환경 변수 | 적용값 | 의미 |
|---|---:|---|
| `TEAM14_TOF_OBS` | 1 | ToF 관측 사용 |
| `TEAM14_TOF_LEAD_HOLD_S` | 0 | 앞차 관측 유지 기능 끔 |
| `TEAM14_TOF_LEAD_GAP_WINDOW` | 0 | 앞차 거리 윈도우 기능 끔 |
| `TEAM14_TOF_REAR_DENSITY` | 0 | 후방 밀도 입력 끔. ToF만 켰을 때 이 변수의 기본값은 1 |

135대/시간 실험의 변경은 학습용 SUMO 설정에 적용한다. 교차로 재생과 100회 비교는 원래 90대/시간 환경에서 진행한다. 학습 중 위험 관측에서는 탐색 행동을 샘플링하고, 재생에서는 학습한 정책의 평균 가감속 명령을 사용한다.
