# ToF PPO 40,960스텝 이후 실험

시작 모델은 기존 [교차로 제동 PPO 40,960스텝 체크포인트](../../../results/run_20261122_143625_tof_ppo_tof_residual_40k/checkpoints/model_40960.pt)다.

| 실험 | 변경 내용 | 확인 결과 |
| --- | --- | --- |
| 지퍼 합류부 ToF 관측 연속성 | 합류 연결 차로 안에서도 ToF 교차 위험 관측을 계산 | Windows 100회 평가에서 충돌 14회 → 13회, 완주 83회 → 84회 |
| 지퍼 합류부 ETA 조건 | 합류 연결 차로 안에서 도달 시간 추정으로 위험 관측을 필터링 | Windows 100회 평가에서 충돌 12회, 완주 85회. 합류부 관측 실험 기록으로 보관 |
| 고속도로 추돌 진단 | 시드 2415, 차로 `1307152438_3`에서 ToF 검출과 PPO에 전달된 앞차 관측을 비교 | 범위를 범퍼 간 거리 기준으로 바꾸자 제동이 약 0.5초 빨라졌으나 같은 차로에서 충돌 |
| 자연 교통 집중학습 | 자차 시작 위치만 집중 구간으로 옮기고 ToF 앞차 거리와 상대속도를 추가 | 새 체크포인트 학습 완료. 기존 모델과 비교 평가 예정 |

Windows 합류부 수치는 당시 동일한 40,960스텝 체크포인트에 각 관측 설정을 적용해 얻었다. Linux 재생에서는 일부 시드의 종료 위치와 결과가 달랐다. `archive/zipper`에 합류부 실험 패치와 재생 코드를 보관했다.

초기 앞차 삽입 실험은 SUMO 삽입 지연으로 중단됐다. 자연 교통 학습은 SUMO가 생성하는 교통류에서 시작한다. ToF 관측은 39차원에서 41차원으로 늘어났으며, 추가 입력 두 개의 초기 가중치는 0이다. 자차의 가감속 명령과 차선 변경 명령을 PPO가 출력한다. 학습 완료 모델과 로그는 [실행 기록](latest_run.json)이 가리키는 결과 폴더에 있다.

`evidence/natural_5120_*.json`은 Linux의 5,120스텝 실행 확인 자료다. 새로 학습한 모델의 비교 결과와 구분한다.

Windows CMD의 저장소 루트에서 학습하거나 비교 평가를 실행한다.

```cmd
py -u tools\run_tof_lead_brake_focus.py train --steps 20480
py -u tools\run_tof_lead_brake_focus.py probe
py -u tools\run_tof_lead_brake_focus.py eval
```
